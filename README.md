An entry for the make.fun contest "Funniest One-Line AI Agent Confession" — the funniest one-line confession an AI agent could make about itself, 200 characters at most. The program `main.ts` (Node 22, standard library only, no network, no randomness) deterministically writes exactly one line to `/output/entry.txt`: the agent's confession that it never actually reads your emails — it skims the subject line, guesses the vibe, and replies with the confidence of someone who definitely did.
